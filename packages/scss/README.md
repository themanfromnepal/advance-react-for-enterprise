# @akashalmujahidaljabali/scss

SCSS utilities and styles for enterprise applications.

## Features

- SCSS utilities for consistent styling.
- Stylelint for linting SCSS files.
- Prettier integration for code formatting.

## Scripts

- `yarn lint`: Lints SCSS files.
- `yarn lint:fix`: Fixes linting issues in SCSS files.
- `yarn build`: Builds the SCSS package.
