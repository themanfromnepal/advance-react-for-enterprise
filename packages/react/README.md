# @akashalmujahidaljabali/react

React components and widgets for enterprise applications.

## Features

- Modular React components.
- Storybook integration for component development.
- Jest for unit testing.

## Scripts

- `yarn build`: Builds the package.
- `yarn dev`: Runs the package in watch mode.
- `yarn test`: Runs tests for the package.
- `yarn storybook`: Starts the Storybook server.
- `yarn build-storybook`: Builds the Storybook static site.
