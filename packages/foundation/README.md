# @akashalmujahidaljabali/foundation

Foundational utilities and shared code for the monorepo.

## Features

- Shared TypeScript utilities.
- Babel configuration for transpilation.

## Scripts

- `yarn build`: Builds the package.
- `yarn dev`: Runs the package in watch mode.
- `yarn test`: Runs tests for the package.
