# React Playground

This folder contains a React playground for testing and developing React components from the monorepo.

## Features

- **Component Testing**: Test and preview React components in isolation.
- **Integration with Monorepo**: Uses components and utilities from the monorepo packages.
- **Hot Reloading**: Automatically reloads the app during development for a seamless experience.

## Getting Started

### Installation

Ensure you have bootstrapped the monorepo by running the following command in the root directory:

```sh
yarn bootstrap
```
